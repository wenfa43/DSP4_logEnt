## 📖 程式簡介

Duplicate Slayer Pro v5 是一套專門的「重複檔案比對與刪除工具」，專為快速找出硬碟中重複的文件、圖片與影片所設計。
程式具備即時的多格式檔案與多頁面預覽功能（V5 版授權後解鎖影音播放功能），讓您在進行整理或刪除前能先確認檔案內容，以避免誤刪重要資料。

### ✨ V5 版本升級重點
* **新版 UI**：全新介面，支援中、英文語言切換。
* **搜尋效能**：優化搜尋與比對邏輯，比對大容量檔案更快速精確。
* **影音功能**：新增大容量檔案搜尋與常見影音格式播放功能。
* **RSA 授權機制**：新增 RSA 授權碼驗證（免費版支援首幀預覽；Pro 版解鎖完整播放）。

## ⚠️ 注意事項與免責聲明

1. **永久刪除風險**：本程式執行的刪除動作**無法從資源回收桶還原**。在刪除檔案前，請務必再三確認檔案內容或事先備份重要資料。
2. **授權與限制**：預設為免費版（部分影音僅提供首幀預覽）。如需取得 Pro 完整版授權，請直接透過 Email 聯絡開發者。
3. **權限問題**：如果遇到刪除失敗，可能是因為檔案設定為唯讀、正在被其他系統程式使用，或權限不足，請自行前往指定路徑處理。
4. **免責聲明**：本程式僅供教學與個人整理使用，作者不對任何誤刪檔案或資料遺失的後果負責。

## 🌐 English Overview

**Duplicate Slayer Pro v5** is a Windows utility tool designed to scan, detect, and clean duplicate files (documents, images, and videos) efficiently.

### Key Features:
* **Multi-Language UI**: Supports both English and Traditional Chinese interface switching.
* **Smart Matching**: Optimized comparison algorithm for large files and high precision.
* **Media Preview/Playback**: Supports image preview and audio/video playback (Pro license unlocks full playback).
* **RSA Verification**: Built-in RSA license system (Free Edition vs. Pro Edition).
* **100% Offline**: No internet access required, ensuring your privacy and data security.
